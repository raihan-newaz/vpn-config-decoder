# Universal VPN Config Decoder & Encoder

A fast, modern web application to decode, inspect, and verify tunnel configuration files.

## Features
- **Dark Tunnel (.dark / darktunnel://)**: Native local/offline decryption (AES-CFB + MsgPack).
- **HTTP Custom (.hc)**
- **HTTP Injector (.ehi)**
- **NPV Tunnel (.npv / .npv4)**
- **SSC Custom (.ssc)**
- **Instant Quick-View**: Extracts Server Host, Port, Username, Password, and Payload into a quick-copy card.
- **Vercel Serverless Ready**: Designed for 1-click deployment on Vercel.
